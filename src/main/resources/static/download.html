지원 환경

운영체제지원 아키텍처최소 버전
Windowsx64 (Intel·AMD 64비트), arm64 (Snapdragon 등)Windows 10 이상
macOSarm64 (Apple Silicon M1~M4), x64 (Intel Mac)macOS 12 Monterey 이상

내 PC 확인: Windows 설정 → 시스템 → 정보 → 시스템 종류 ("x64 기반" / "ARM 기반"), macOS 메뉴 → 이 Mac에 관하여 → 칩 ("Apple M…" = arm64, "Intel" = x64)

설치·실행 방법

Windows

  1. Chzzk-Setup-win-x64.exe(ARM PC 는 arm64)를 내려받아 실행합니다.
  2. 코드 서명 인증서가 없는 앱이라 "Windows의 PC 보호" 창이 뜹니다 → 추가 정보 → 실행.
  3. 설치 위치를 고르고 설치 → 바탕화면·시작 메뉴의 치지직 으로 실행합니다.
  4. 설치 없이 쓰려면 Chzzk-win-x64.zip 을 풀고 Chzzk.exe 를 실행합니다.
  5. 삭제: 설정 → 앱 → 설치된 앱 → Chzzk → 제거

macOS

  1. 칩에 맞는 Chzzk-mac-arm64.dmg(Apple Silicon) 또는 Chzzk-mac-x64.dmg(Intel)를 내려받아 엽니다.
  2. Chzzk 아이콘을 Applications 폴더로 끌어 놓습니다.
  3. Apple 공증을 받지 않은 앱이라 처음 실행 때 막힙니다. 한 번만 허용하면 됩니다:
    • macOS 15 이상: 실행 시도 → 시스템 설정 → 개인정보 보호 및 보안 아래쪽 "그래도 열기" → 암호 입력
    • macOS 14 이하: Finder 의 응용 프로그램에서 Chzzk 를 Control-클릭 → 열기 → 열기
    • "손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에서 xattr -dr com.apple.quarantine /Applications/Chzzk.app 실행 후 다시 열기
  4. 삭제: 응용 프로그램 폴더의 Chzzk 를 휴지통으로

처음 실행하면

앱은 이 서버()에 연결되어 라이브 · 다시보기 · 지난 방송 목록을 보여줍니다. 카드를 누르면 재생되고, 목록은 10초마다 새로 고쳐집니다. 다른 서버에 연결하려면 오른쪽 위 서버 설정에서 주소를 바꿉니다.
