# 송출 키를 없애고 송출 제어도 소유자 검사로 통일한다

2단계에서는 로그인이 없어서 방송을 시작한 기기에만 주는 송출 키로 송출·종료 권한을 표시했다. 3단계에서 로그인이 생기고 송출 WebSocket 연결에도 세션이 실려 오므로, 서버가 "연결한 사용자 = 방송 소유자"인지 직접 확인할 수 있다. 권한 확인 경로가 둘(키, 소유자)이면 한쪽만 막혀도 우회될 수 있으므로 송출 키를 제거하고, 송출 연결·종료·수정·삭제를 모두 소유자 검사 하나로 판단한다. 같은 소유자가 다른 기기에서 송출 화면을 다시 열면 이전 송출 연결은 끊기고 새 연결로 바뀐다.
